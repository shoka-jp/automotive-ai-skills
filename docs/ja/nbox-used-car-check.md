# 中古N-BOXの購入前に確認したいこと

中古のN-BOXを見に行く前に、車の情報、整備記録、リコールへの対応状況を整理しておくと、売主や整備工場に具体的な質問ができます。このページでは、日本向け **JF3・JF4** を例に確認の進め方を紹介します。

[**N-BOXの購入前チェックを試す →**](https://shoka-jp.github.io/automotive-ai-skills/tools/vehicle-brief.ja.html?vehicle=nbox&task=buy)

ツールは登録や診断機を使わずに、確認メモとAIへの質問文を作成します。**AIによる診断や、リコール対象・改修完了の判定は行いません。**

## 最初に確認する記録

- 型式、製作時期、走行距離と、分かる範囲の使用履歴。初度登録年と製作時期は同じとは限りません。
- 点検・整備記録、修理や部品交換の内容、記録が残っていない事項。
- 警告灯や気になる症状についての売主の説明と、実際に確認できたこと。
- リコールの個別対象と実施状況を確認した日、確認先、記録。個別の照会はメーカーや販売店に依頼します。

情報がない場合は空欄や「未確認」のままにし、推測で埋めないことが大切です。車台番号・氏名・連絡先をツールや公開のIssueに入力しないでください。

## 燃料ポンプのリコールをどう確認するか

Hondaの[リコール届出5423](https://www.honda.co.jp/recall/auto/info/231208_5423.html)には、N-BOXを含む複数車種が掲載されています。Hondaは低圧燃料ポンプの識別マークを確認し、該当する場合は対策品に交換すると案内しています。[国土交通省の届出案内](https://www.mlit.go.jp/report/press/jidosha08_hh_004984.html)にも、改善措置の訂正が記載されています。

**車名・型式・年式が近いだけで、その車の対象や交換の要否、実施完了を判断することはできません。** Hondaの表には複数の車台番号範囲があり、個別の確認が必要です。

販売店などには、例えば次のように確認できます。

1. この車について、届出5423の対象と対応状況をいつ・どこで確認しましたか。
2. 識別マークの確認結果や、該当する場合の交換記録はありますか。
3. 未確認の項目があれば、どこで確認できますか。

結果は「識別確認で対象外」「交換実施済み」「未確認」を分けて記録します。過去の別の対策だけで今回の状況を決めないようにします。

## ツールの使い方

1. [N-BOX購入前チェック](https://shoka-jp.github.io/automotive-ai-skills/tools/vehicle-brief.ja.html?vehicle=nbox&task=buy)を開きます。
2. **N-BOX・購入前**のサンプルを押すと、JF3・2019年・日本向けの例と、参照資料を表示します。これは説明用の架空の条件です。
3. 実際に相談するときは型式や製作年などを分かる範囲で選び、資料の範囲と出典を確認します。質問文をコピーして任意のAIに渡せます。

AIの回答は確認漏れを減らすための補助です。回答だけで安全性や故障部品を決めず、必要に応じて独立した専門家による現車確認を受けてください。
