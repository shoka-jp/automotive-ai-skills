# 車両確認メモのCLI

[English](./vehicle-brief-cli.md) | [README](../README.ja.md)

本リポジトリを取得し、Node.js 22以降で実行します。同梱資料を読み込むため、通信・AIサービス・APIキーは不要です。出典の最新情報への更新、実車点検、車台番号によるリコール個別照会は行いません。

## 整備相談用の確認メモを作る

```sh
node scripts/vehicle_brief.mjs --vehicle JF3 --market Japan --year 2019 --task buy --lang ja --format checklist > checklist.txt
```

車両情報、今回の確認事項、関連資料の候補と限界をテキストファイルに保存します。AIへの指示は含めません。記載される質問は、点検済みの結果や安全性の判定ではありません。共有前に保存内容を確認してください。

上記の車両情報は入力例です。確認できた情報に置き換えてください。製造年と初度登録年は区別します。

## 出力に含める内容を選ぶ

| オプション | 動作 |
|---|---|
| `--format prompt` | 既定値。従来のAI質問文を作成します。 |
| `--format checklist` | 人が読む確認メモを作成します。 |
| `--omit-notes` | エンジン・走行距離・履歴の欄と相談内容を「【共有用に省略】」へ置換します。選択した出力形式に適用され、値の指定は不要です。 |
| `--context "..."` | 分かっているエンジン・走行距離・履歴を指定します。任意です。 |
| `--concern "..."` | 相談内容を指定します。任意で、引用データとして扱います。 |
| `--lang en` / `--lang ja` | 言語を指定します。既定値は英語です。 |
| `--help` | 車種・目的・オプションの一覧を表示します。 |

`--omit-notes` を使っても、車種・型式・製造年・仕向けは残ります。匿名化する機能ではありません。コマンドの引数に車台番号・氏名・連絡先を入力しないでください。シェルの履歴に残る場合があります。CLIの省略指定はどちらの出力形式にも適用します。ブラウザー版の省略チェックは確認メモだけに適用します。

```sh
node scripts/vehicle_brief.mjs --vehicle JF3 --market Japan --year 2019 --lang ja --format checklist --omit-notes > checklist-ja.txt
```

`--format` のない既存の呼び出しは、引き続きAI質問文を出力します。不正な形式・値の不足・同じオプションの重複・不正な製造年は、終了コード2で失敗し、本文を出力しません。シェルの `>` は失敗する前に保存先を作成・上書きする場合があるため、新しいファイル名を使い、終了コードを確認してください。

## 不明なことを残す

`--market Japan` は日本向けであると確認できた車に指定します。`other`・`unknown` の場合は日本向け資料を添付せず、共通の確認事項を残します。型式と製造年の範囲はブラウザーと同じ方法で照合します。資料の一致は故障・リコール対象・対策完了・安全性を確定するものではなく、一致なしも問題がない証拠にはなりません。[資料の選択方法](./model-reference-routing.ja.md)と[品質と限界](./quality.ja.md)も確認してください。
