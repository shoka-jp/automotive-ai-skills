# Repair Estimate Reviewer（修理見積もりレビュー）

[English](./README.md) | **日本語**

修理を承認する前に、見積書の作業範囲、根拠、計算、未確認事項を比較します。

## 説明

総額が安くても、部品・工賃・付随作業の範囲が異なることがあります。明細付きの見積もりを比較表に整理し、工場に確認する質問を作成します。車両の診断、相場価格の認定、安全に関わる修理の延期判断は行いません。

**対象者:** 修理提案を検討する所有者、サービスアドバイザー、中古車販売店、車両管理の購買担当者。

## できること

- 部品、数量、新品・再生品等の区分、作業時間と単価、消耗品、税、諸費用、対象外項目を抽出する。
- 見積書に明示された通貨と課税条件で再計算し、不明な値は不明のまま残す。
- 作業範囲の違いや工賃の重複の可能性を、過剰請求と断定せず整理する。
- 根拠のある修理、定期整備、任意の作業、要確認項目を区別する。
- 書面の保証条件や見積有効期限を、適用範囲を作り上げずに比較する。
- 診断結果や明細を求める質問と、明確な承認範囲の下書きを作る。

## プロンプト例

```text
米国仕様の2016年ホンダ・シビック2.0Lガソリン、120,000km。
エアコンの見積もり2件を比較したいです。一方は漏れ診断を含み、
もう一方は冷媒サービスだけです。価格比較の前に不足する作業範囲を示してください。
```

```text
国内仕様の2018年トヨタ・アクア1.5Lハイブリッド、95,000km。
架空の見積もりは部品12,000円、工賃1.5時間×8,000円、消耗品1,000円。
すべて税別で小計全体に10%課税という入力条件です。計算を確認し、
この数字を実際の相場や税法の説明として扱わないでください。
```

```text
英国仕様の2015年VWゴルフ1.4 TSI、140,000km。分解作業を共有する
可能性のある2作業に別々の工賃があります。二重請求と決めつけず、
それぞれに含まれる工程を確認する質問文を作ってください。
```

```text
国内仕様の2020年日産リーフ40kWh、80,000km。駆動用バッテリーの
修理提案がありますが、診断結果と保証条件がありません。
EV専門業者に聞く質問を作成してください。DIY手順は不要です。
```

## 推奨ワークフロー

1. **背景と書類を集める。** 車両情報、走行距離、市場、症状、診断結果、見積日、通貨、税の表記、関連する全明細を確認します。氏名、住所、決済情報、不要な識別情報を伏せます。
2. **欠けた情報を補作せず整理する。** 項目・作業、根拠、部品と数量、工賃の算定方法、その他費用、税区分、含む・含まない作業、不明点を表にします。時間が示されていない一式工賃は一式のまま扱います。
3. **計算を確認する。** 数量×単価、明示された作業時間×工賃単価、記載済みの費用と課税条件だけで計算します。差額と丸めの前提を示し、税込・税別や数量が不明なら総額を決めず質問します。
4. **同じ範囲で比較する。** 部品区分、診断、校正、アライメント、油脂、処分費、保証など、該当する差を示します。共通作業の工賃は確認事項とし、重複請求と断定しません。
5. **根拠から質問を絞る。** 修理を裏付ける所見と、定期整備のメーカー基準を確認します。緊急性は専門家の点検に基づき、節約のためにブレーキ・操舵・SRS・燃料・高電圧系の対応延期を勧めません。
6. **判断材料をまとめる。** 比較表、計算、未確認事項、最大5つの質問を返します。承認済みの範囲は別記し、依頼なしに作業承認・予約・連絡を行いません。

## 制限事項

- 価格は地域、時期、仕様、部品、作業範囲で変わります。総額だけで「適正」「不正」と評価しません。
- 見積書は診断の正しさを証明しません。故障の調査は[Vehicle Troubleshooting](../vehicle-troubleshooting/README.ja.md)と専門家の点検に引き継ぎます。
- 適合、仕様、作業手順は純正資料で確認します。安全に関わる実作業は専門家に委ねます。
- 税、消費者の権利、保証条件は地域と時点で異なります。[確認用資料](../../docs/vehicle-service-sources.md)を起点に該当地域の最新一次資料を確認します。法的紛争や保証適用の可否を決定するスキルではありません。
