# Used Car Listing Assistant（中古車販売説明アシスタント）

[English](./README.md) | **日本語**

記録で裏付けられる情報から、状態の説明と価格内訳が明確な中古車の掲載原稿を作成します。

## 説明

車両情報を集めた後の販売準備を支援します。タイトル・紹介文・購入希望者向けFAQを作る前に根拠一覧を作成し、裏付けのない主張や不足書類を販売者に示します。購入前点検と補完関係にあり、査定、現車確認、地域の広告規則への適合確認を代替しません。

**対象者:** 中古車販売店、営業担当者、正確な車両広告を準備する個人売主。

## できること

- 仕様、装備、整備記録、既知の不具合、検査履歴、保証条件を整理する。
- 売主の申告、書類で裏付けた事実、観察結果、未確認の主張を分ける。
- 無事故、所有者数、整備履歴を補作せず、読みやすい掲載文と回答案を作る。
- 装備だけでなく既知の傷や損傷も示す写真チェックリストを作る。
- 価格の計算、必須費用、任意項目、表示総額の前提条件を確認する。
- 未確認の主張と人による確認事項を残した掲載前チェックリストを作る。

## プロンプト例

```text
国内仕様の2019年トヨタ・プリウス1.8Lハイブリッド、82,000km。
整備請求書、鍵2本、バンパーの傷の写真がありますが、骨格部位の
修復歴の確認書はありません。「無事故」と断定せず掲載文を作成してください。
```

```text
英国仕様の2017年マツダMX-5、2.0Lガソリン、MT、65,000km。
整備記録は私の所有期間の分だけです。「全履歴あり」に変えず、
正確な紹介文と必要な写真の一覧を作成してください。
```

```text
国内仕様の2020年日産リーフ40kWh、52,000km。メーターの推定航続距離は
分かりますが、バッテリーの健全性試験はありません。表示値と実測容量、
航続距離の保証を区別した購入希望者向けFAQを作ってください。
```

```text
国内仕様の2018年ホンダN-BOX、660ccガソリン、60,000km。
車両価格90万円、必須の諸費用は適用される税を含め合計8万円、任意保証3万円です。
価格表を作り、登録・納車条件の不足を指摘し、現行の広告表示資料を確認してください。
```

## 推奨ワークフロー

車種別の確認には[資料の選び方](../../docs/model-reference-routing.ja.md)に従って、型式・製造年・仕向けに合う資料を参照します。[チェックメーカー](../../tools/vehicle-brief.ja.html)でも質問文を作れます。資料の一致だけで故障・対象・対策完了を断定しません。

1. **車両情報と市場を確認する。** 年式・初度登録、メーカー、車種、動力源、グレード、走行距離と単位、所在地、事業者・個人の別、装備、記録、不具合、価格条件を整理します。掲載先の最新の要件も確認します。
2. **根拠一覧を作る。** 主張、資料と日付、確認済み・売主申告・不明の区分、使用できる表現を示します。資料がない項目は不明とし、見た目のきれいな写真やオークション評価点だけで事故歴を判断しません。
3. **重要な不足を解消する。** 状態の告知、走行距離履歴、点検所見、保証条件、価格内訳の不足を確認してから掲載可能と判断します。未確認事項は顧客向け原稿の外に目立つ確認リストとして残しますが、既知の不具合をそこだけに隠しません。
4. **総額を確認する。** 車両価格と明示された必須費用を、本当に任意の項目から分けます。指定された税込・税別の条件を使い、二重計上しません。必須費用が不明なら支払総額は未確定です。日本では自動車公正取引協議会の最新資料と適用範囲を確認し、他国へそのまま適用しません。
5. **掲載原稿を作る。** 事実に基づくタイトル、短い説明、仕様・状態表、見える位置の不具合告知、価格内訳、写真一覧、FAQを返します。根拠のない最上級表現、購入の催促、認定や保証の約束を避けます。
6. **公開前に照合する。** 各主張を根拠、最新の地域・掲載先の要件と照合します。公開資料から前所有者の個人情報や不要な書類識別情報を除き、必要な表示は残します。実際の公開は販売者からの別途の指示に基づきます。

## 制限事項

- 現車点検、書類の真正性確認、所有権の判断、履歴の認定はできません。専門家の点検と原本を優先します。
- 「修復歴」、外装等の通常修理、事故歴は同義ではありません。より強い断定に置き換えたり翻訳したりせず、[確認用資料](../../docs/vehicle-service-sources.md)と適切な査定担当者に確認します。
- 不具合の隠蔽、距離の虚偽表示、架空の口コミ、販売写真からの損傷除去は行いません。不明を「なし」に変えません。
- 価格、告知・表示のルール、保証上の責任は売主の区分、地域、時点で変わります。法的適合の認定や価格査定を行うスキルではありません。
- ブレーキ、操舵、SRS、燃料、高電圧系の懸念は専門家の評価が必要です。魅力的な広告は走行安全性の証明にはなりません。
