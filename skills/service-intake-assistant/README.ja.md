# Service Intake Assistant（整備受付アシスタント）

[English](./README.md) | **日本語**

運転者の説明を整理し、診断結果を作り上げずに、整備受付票と整備士への申し送りを作成します。

## 説明

診断前の聞き取りとして、何が起き、どの条件で発生し、何を確認済みかを整理するスキルです。顧客の申告、整備士の確認結果、未検証の仮説を分けます。原因の調査はVehicle Troubleshooting、見積書の比較はRepair Estimate Reviewerに引き継ぎます。

**対象者:** サービスアドバイザー、整備工場、車両管理担当者、入庫前に状況をまとめたい所有者。

## できること

- 症状の経過、頻度、発生条件、警告表示、直近の整備を聞き取る。
- 顧客の表現を残しながら、整備士が把握しやすい申し送りにまとめる。
- 走行可能と断定せず、専門家による確認が必要な安全上の懸念を示す。
- 取得済みのスキャン結果・写真・録音に出典と日付を付け、「未確認」と「正常」を区別する。
- 診断の承認、予算上限、連絡希望と、部品交換の承認を分けて記録する。
- 顧客確認用の要約と、次に尋ねる重要な質問3点を作成する。

## プロンプト例

```text
米国仕様の2018年トヨタ・カローラ、1.8Lガソリン、AT、92,000km。
顧客によると冷間始動直後だけ異音があり、スキャンは未実施です。
受付票と追加の質問3点を作成してください。
```

```text
国内仕様の2020年日産リーフ40kWh、68,000km。公共充電器で時々
充電が止まる一方、自宅では充電できるとの申告です。診断はせず、
EV担当整備士に渡す申告内容と未確認事項を分けてください。
```

```text
英国仕様の2017年マツダ3、2.0Lガソリン、110,000km。
タイヤ交換後に振動が出ました。請求書はありますが点検結果はありません。
タイヤの不良と断定したり試走を勧めたりせず、申し送りを作ってください。
```

```text
国内仕様の2019年ホンダ・フィット1.3Lガソリン、75,000km。
顧客が承認したのは診断費5,000円までで、修理は未承認です。
費用や納期を約束せず、この範囲と連絡希望をまとめてください。
```

## 推奨ワークフロー

1. **車両と依頼内容を確認する。** 年式、メーカー、車種、動力源、変速機、走行距離、市場、主訴、直近の作業を集めます。書類は必要な箇所だけを使い、個人情報を除きます。
2. **緊急性を先に確認する。** 制動・操舵の異常、煙、燃料臭、重大な過熱、高電圧系の警告があれば、診断実験を止め、専門家やロードサービスへの相談を優先します。危険な症状の再現を顧客に求めません。
3. **経過を整理する。** 発生開始、頻度、冷間・温間、既に観察した速度や負荷、表示、直前の変更を確認します。最初の追加質問は申し送りに重要な3点に絞ります。
4. **根拠を区別する。** 「顧客申告」「記録で確認」「仮説」「未確認」に分類します。故障コードは手がかりであり、部品交換が必要という証明ではありません。
5. **受付票を出力する。** 車両情報、主訴、条件と経過、日付・出典付きの根拠、安全上の懸念、未確認事項、次に依頼する評価を記載します。診断承認や予算は明示された場合だけ記録し、不明なら「承認待ち」とします。
6. **申し送りを確認する。** 顧客に要約の訂正を依頼し、試験内容と走行可否は担当専門家に判断してもらいます。連絡文は送信を依頼されるまで下書きとして扱います。

## 制限事項

- 文章・録音・写真だけでは走行可否や故障箇所を確定できません。「警告灯の申告なし」を「異常なし」に変換しません。
- 工場での試験や修理承認は行いません。ブレーキ、操舵、SRS、燃料系、EV高電圧系の実作業は、純正手順に従う有資格・専門の作業者に委ねます。
- 予約枠、診断時間、料金、保証適用、顧客同意は最新の記録で確認し、推測しません。
- 市場ごとに用語や承認手続きが異なります。必要時に最新の地域別資料を確認します。[確認用資料](../../docs/vehicle-service-sources.md)も参照してください。
