# Vehicle Recall Checker（リコール確認アシスタント）

[English](./README.md) | **日本語**

最新の公式情報を使って個別車両のリコール確認を進め、未確認の範囲を記録します。

## 説明

車種単位のリコール届出だけでは、その車が対象か、改修済みかは確定できません。届出の発見、個別車両への適用、作業完了の根拠を分けるスキルです。公式照会の準備とメーカー・販売店への問い合わせを支援し、データベースへのアクセス自体を保証するものではありません。

**対象者:** 所有者、中古車の購入者・販売者、サービスアドバイザー、車両管理担当者。

## できること

- 元の販売市場と現在の所在地に合う行政機関・メーカーの情報源を選ぶ。
- リコール、その他のキャンペーン、技術情報、不具合の申告を区別する。
- 届出番号、対象仕様、公表日・確認日、公式の指示、適用が未確認の点を記録する。
- 提供された公式の照会結果を読み、「未実施なし」の意味を過大解釈しない。
- 未実施を確認、実施済みを確認、対象候補、未確認を分ける。
- 販売店への問い合わせ文と、確認を終えるために必要な根拠をまとめる。

## プロンプト例

```text
国内仕様の2018年トヨタ・プリウス1.8Lハイブリッド、90,000km。
型式と車台番号は手元にあります。番号全体を公開させずに公式の照会先を
案内してください。対象のリコールがあるとは決めつけないでください。
```

```text
米国仕様の2016年ホンダ・シビック2.0Lガソリン、100,000マイル。
現在の公式VIN照会結果は未改修リコール0件でした。この結果の限界と、
過去の改修を「完了」と説明するための根拠を教えてください。
```

```text
日本向けの2015年マツダ・ロードスター1.5Lガソリン、70,000kmで、
現在は英国に輸入されています。車台番号は17桁のVINではありません。
確認する公式情報と、輸入者・メーカーへの質問を整理してください。
```

```text
国内仕様の2020年日産リーフ40kWh、65,000km。売主は全リコール対応済みと
説明していますが、手元には一般的な届出文しかありません。
完了と認定せず、根拠一覧と販売店への問い合わせ文を作ってください。
```

## 推奨ワークフロー

1. **確認範囲を特定する。** 年式、メーカー、車種、動力源、元の販売市場、現在の国、輸入歴、手元の通知や照会結果を集めます。必要に応じて初度登録年とモデル年を区別します。
2. **適切な識別番号を非公開で使う。** VIN・車台番号は所有者が公式サイトへ直接入力できるよう案内します。解釈には必要な範囲を残して伏せた結果を使い、公開報告に番号全体を載せません。別形式の車台番号をVINに合わせて水増し・切り詰め・創作しません。
3. **最新の一次資料を確認する。** [公式情報の案内](../../docs/vehicle-service-sources.md)からメーカー照会へ進みます。年式・車種検索は対象候補の発見に使い、個別適用はメーカー確認で確かめます。輸入車では元の市場の情報と現地の正規窓口の対応範囲を確認します。
4. **根拠と限界を記録する。** 届出番号・区分、公式情報源、確認日、個別車両との照合根拠、状態、指定された次の対応を表にします。個別車両の公式記録や信頼できる作業記録がある場合だけ「実施済み」とします。資料が矛盾する場合は両方を残し、確認を依頼します。
5. **0件や検索不能を限定的に解釈する。** どの情報源で何が表示されたかを明記します。「この照会で未実施が表示されない」は、過去のリコールなし、他キャンペーンなし、安全な車という意味ではありません。アクセスできない場合は検索結果の断片から推測せず、未確認とします。
6. **実際の通知に従う。** 公式の運転停止・駐車・充電に関する指示があれば、正確に目立つ形で示します。指示を作ったり緩めたりしません。対策の提供状況と完了記録はメーカー・販売店に確認し、根拠なしに費用負担、適用、予約枠を約束しません。

## 制限事項

- データベースには直近の届出、実施済み作業、古い情報、市場外の車両が含まれない場合があります。現在の検索サービスが示す収録範囲を確認します。
- 車台番号の範囲内でも対象外の車両が含まれることがあります。技術情報や不具合申告が、そのままリコールや無償修理の権利になるわけではありません。
- リコール検索は現車点検や走行許可の代わりになりません。ブレーキ、操舵、SRS、燃料、EV高電圧系の作業は、該当する純正手順に従う専門家に委ねます。
- ブラウズやメーカー照会ができない場合は、確認先と未回答事項を提示します。届出、状態、出典、完了記録を作り上げません。
