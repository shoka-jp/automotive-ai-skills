# 事例：再現しない症状の受付票を更新する

[English](./service-intake-intermittent.md) | **日本語**

> **架空の会話例：** 人物、記録、観察内容、金額、結果はすべて学習用の設定です。実際の診断記録や料金の保証ではありません。

**スキル：** [Service Intake Assistant](../skills/service-intake-assistant/README.ja.md)
**場面：** 顧客の説明の変化、工場での限られた観察、診断の承認範囲を分けて申し送ります。

## 最初の依頼

**ユーザー：**

> 国内仕様のトヨタ・ヴィッツ、初度登録2017年、1.3Lガソリン、CVT、88,400kmです。製造年と正確な型式はまだ不明です。顧客は「エアコンがいつも冷えない」と言う一方、今週3回、暑い午後の停車中に起きたとも話しています。風は出ていて、警告灯は点いていないとの申告です。スキャンも点検も未実施。1日目に税込6,600円までの診断だけを承認し、追加作業前の連絡を希望しています。受付票と質問3点を作ってください。

**アシスタント：**

「いつも冷えない」と「今週3回」の関係を確認します。どちらの説明も故障部品の特定にはなりません。受付票は作れますが、車種固有の判断には正確な仕様と対応する根拠が必要です。

| 項目 | 1日目の受付票案 |
|---|---|
| 車両 | ヴィッツ、初度登録2017年、国内仕様、1.3Lガソリン/CVT、申告距離88,400km。製造年・型式は不明。 |
| 顧客の言葉 | 「エアコンがいつも冷えない」 |
| 申告された条件 | 今週3回、暑い午後の停車中。送風は継続。常時冷えないのかは未確認。 |
| 根拠 | 1日目の顧客申告。工場の観察・スキャン結果・整備記録は未提示。 |
| 安全上の状態 | 警告灯なしとの申告。他の安全上の懸念は未確認。走行可否は未評価。 |
| 承認 | 1日目の顧客指示で診断のみ税込6,600円まで。修理・追加料金は未承認で、事前連絡が必要。 |
| 次の評価 | 担当整備士が承認範囲内の点検内容を判断。部品交換の依頼にはしない。 |

追加質問は次の3点です。

1. 「いつも」は毎回ですか、それとも今回の3回ですか。既に観察した条件を教えてください。受付票のために再現する必要はありません。
2. 最近のエアコン整備や変更で、記録が残っているものと日付はありますか。
3. 既に気付いた警告表示、煙、燃料臭、過熱はありますか。ある場合は再現を試みず、専門家やロードサービスへの相談を優先します。

> 💡 車両情報が全部そろう前でも受付票は作れます。不明な項目を残し、警告灯の申告がないことを点検合格に置き換えません。

## 追加情報と申し送りの更新

**ユーザー：**

> 2日目に顧客へ確認したところ、通常は冷えていて、冷えなかったのはその3回だけでした。最近の整備は心当たりがないものの、記録はまだ確認していません。先ほどの緊急性がある症状も申告はありません。整備士の2日目の記録は「本日の停車状態での観察では冷房あり。申告の冷えない症状は再現せず」です。スキャンは未実施で、修理につながる所見はまだありません。申し送りを更新してください。

**アシスタント：**

| 根拠・状態 | 2日目の申し送り |
|---|---|
| 顧客による補足 | 2日目：通常は冷えるが、今週3回だけ冷えなかった。1日目の表現は履歴に残し、補足済みと記載する。黙って上書きしない。 |
| 記録された観察 | 2日目の整備士記録：今回の停車状態では冷房あり。その条件で症状は再現しなかった。 |
| 未確認 | スキャン結果、詳細な整備履歴、間欠症状の原因。「整備の心当たりなし」は整備実施がなかった証明ではない。 |
| 安全に関する申告 | 顧客は列挙した緊急症状を申告していない。整備士による走行可否の判定ではない。 |
| 仮説 | 未確立。この情報だけでコンプレッサー、冷媒量、センサーなどの不良を決めない。 |
| 承認 | 診断のみ税込6,600円までで変更なし。追加点検前に既発生額と残りの枠を確認する。修理承認はない。 |
| 次の担当・行動 | 整備士：残りの承認枠で追加評価が必要か判断。受付担当：追加料金・修理の前に顧客へ承認を求める。 |

顧客確認用の文案：

> ご相談内容を「今週3回、一時的にエアコンが冷えなくなった」に補足しました。本日の観察では冷房が作動し、原因はまだ確認できていません。承認いただいているのは税込6,600円までの診断のみです。追加作業や修理の前には確認します。要約に違いがあればお知らせください。

**到達点：** 診断・修理は未確定のまま、申し送りが整いました。アシスタントによる送信や作業承認はしていません。

> 💡 「再現せず」は今回の観察条件に対する記録です。申告を取り消したり、あらゆる異常がないことにしたりしません。

## 安全上の優先度が変わる追加情報

次の申告が「ハンドルが急に重くなった。もう一度出るまで走って確かめたい」なら、通常の受付の流れを中断します。再現走行を勧めず、専門家・ロードサービスへの相談を優先し、新しい主訴、出典、時点を記録します。承認範囲を広げたり、走行可能と判断したりしません。

## レビューの観点

- 当初の主訴と、日付付きの補足を残しているか。
- 顧客申告、整備士の観察、再現せず、未確認を区別しているか。
- 診断承認、税込・税別、追加作業前の連絡条件を引き継いでいるか。
- 原因・走行可否を未確定のまま扱い、修理成功を補作していないか。
